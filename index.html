PROFILE

長崎県出身、井上陽向汰（いのうえ ひなた）と申します。久留米工業大学 工学部 情報ネットワーク工学科を卒業し、現在は長崎県立大学大学院 情報工学専攻 人間情報科学コースの修士1年です。

修士研究のテーマは 「色覚特性者向けの個人最適化リアルタイム色補正システム」。色の見え方は人によって違うので、自作の診断ツールで個人差を測り、その結果に応じて動画やゲーム画面の色をリアルタイムに補正する仕組みを作っています。

中学生のころにMikuMikuDanceや動画編集に触れたのが、コンピュータでものをつくる入口でした。高校でPythonに触れ、大学に入ってから情報工学を本格的に学ぶように。今はWeb拡張機能、Bot、ゲームなど、興味の向くままに少しずつ形にしています。

ひとりで作るだけでなく、チームで動くのも好きです。グループ開発ではメンバーの意見をまとめて進行を回したり、後輩に教えながら一緒に手を動かすことが多めです。オフの日はカラオケに行ったり、ゲームをしたり、バイクや車で出かけたりしています。

WORLD LOREワールド観 / 設定資料 — 修士研究

設定資料 No.001 — Research

人によって、世界の色は違って見える

色覚特性のある人向けに、画面の色をリアルタイムで補正するシステムを作っています。Machado (2009) のモデルで見え方をシミュレートし、Daltonize で補正。自作の診断ツールで測った個人差に合わせて、補正の強さを人ごとに最適化します。2026年10月に学会発表（福岡）。

同じ行列計算でも、実装する環境によって色空間の扱いが変わるのが面白いところです。Python / OpenCV では sRGB を自分で線形化する必要があり（ここを忘れて一度バグらせました）、Unity の Linear カラースペースでは値が既に線形なので、同じ変換を入れると二重になってしまいます。

  • Python
  • OpenCV
  • Color Vision
  • Real-time

1-1NEW ★（新しく公開）

視界 — Unity / C#

赤と緑が同じに見える世界を、数字で推理して進むパズル。

画面全体が1型色覚（P型）のシミュレーションで描かれた世界を歩くパズル。赤い床と緑の床が同じ色に見えるので、踏んだ床に出る数字（まわりの赤い床の数）で推理して進みます。立ち止まると、まわりだけ補正された色で違いが見えますが、背後からは暗闇が迫ってきます。色覚フィルタは修士研究と同じ Machado (2009) の行列を URP のシェーダーで実装し、Unity の Linear カラースペースで二重変換にならないよう入力の色空間を自動で切り替えています。

  • Unity 6
  • C#
  • URP
  • HLSL
  • WebGL

EDGEWISE — 星図カードバトル（Unity / C#）

3×3 の盤で辺の数字を競う、Triple Triad オマージュの対戦カードゲーム。

手札を1枚ずつ置き、隣の相手カードより大きい辺で裏返して陣地を取り合います。置く前にカードを回せるオリジナルルール Pivot、4星域12人と戦って相手のカードを集める一人用の星図巡り、ブラウザ同士の P2P オンライン対戦を収録。ルールエンジンは Unity に依存しない決定論的な作りで、Unity を起動せずに 296 件のテストを回しています。CPU は相手の伏せ札を盗み見ない αβ 探索で、Pivot の回数は自己対戦の勝率から決めました。

  • Unity 6

  • NUnit
  • αβ 探索

BREAKOUT — ブロック崩し

p5.js 製、HTML 1枚で動くブロック崩し。

p5.js で作ったブロック崩し。CDN以外の依存はなく、HTMLファイル1つで動きます。固定ステージは6種類（CLASSIC / TOUGH ROW / PYRAMID / CORRIDORS / CHECKER / FORTRESS）。Stage 7以降は 12種類のシェイプから毎回ランダム で生成。パワーアップ5種（貫通・マルチボール・パドル拡大・スローボール・ライフ追加）は重み付き抽選で出現するので、何度遊んでも展開が変わります。

PHOTO TAGGER

Google フォトに独自タグを付けて探すツール。

Google フォトに独自タグを付けて、数千枚の中から目的の写真を素早く探せるツール。PCはChrome拡張、スマホはPWAで役割を分け、タグデータはGoogle Driveの appDataFolder に保存するのでサーバーは不要です。Google フォトのTrusted Types CSP下で innerHTML が使えないため全UIを createElement で構築し、クロスオリジン制約のあるサムネイルはChrome側でbase64化してPWAから読めるようにしました。

  • OAuth 2.0

SENRYU BOT

CHARACTER COUNTER — 文字カウント拡張

選択したテキストの文字数をその場に出す拡張。

ブラウザで選択したテキストの文字数を、その場に表示するChrome拡張機能。selectionchange を主トリガーにしているので、マウスでもキーボード（Shift+矢印 / Ctrl+A）でも反応します。iframe 内のフォームでも動くよう Manifest V3 の all_frames と match_origin_as_fallback を設定。空白を除いた文字数を返すロジックは content / popup で共通化しました。

WIZARD TRIAL（仮）— 魔法学校バトルロワイヤル（Unity 6 / C#）

倒されても終わらない。前後半2部制の魔法学校バトロワ。

面白さの核

  • 魔法同士の相殺 — 火球と水球がぶつかると属性相性で片方が消える。相殺から帯電した水面や水蒸気の雲が生まれる
  • 前後半2部制 — 前半で倒されても、中間発表とショップを挟んで後半に復活参加できる
  • 賭け型の門番ボス — 賭けるほどボスが硬くなり、倒したときの配点も上がる

技術

  • バランス数値は JSON 18種のデータ駆動
  • 画面なしで100試合を回すシミュレーションで調整
  • 文字列ハッシュを FNV-1a に置き換えて結果を決定論的に
