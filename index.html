PROFILE

長崎県出身、井上陽向汰（いのうえ ひなた）と申します。久留米工業大学 工学部 情報ネットワーク工学科を卒業し、現在は長崎県立大学大学院 情報工学専攻 人間情報科学コースの修士1年です。

修士研究のテーマは 「色覚特性者向けの個人最適化リアルタイム色補正システム」。色の見え方は人によって違うので、自作の診断ツールで個人差を測り、その結果に応じて動画やゲーム画面の色をリアルタイムに補正する仕組みを作っています。

中学生のころにMikuMikuDanceや動画編集に触れたのが、コンピュータでものをつくる入口でした。高校でPythonに触れ、大学に入ってから情報工学を本格的に学ぶように。今はWeb拡張機能、Bot、ゲームなど、興味の向くままに少しずつ形にしています。

ひとりで作るだけでなく、チームで動くのも好きです。グループ開発ではメンバーの意見をまとめて進行を回したり、後輩に教えながら一緒に手を動かすことが多めです。オフの日はカラオケに行ったり、ゲームをしたり、バイクや車で出かけたりしています。

SCREEN 02

WORLD LOREワールド観 / 設定資料 — 修士研究

設定資料 No.001 — Research

人によって、世界の色は違って見える

色覚特性のある人向けに、画面の色をリアルタイムで補正するシステムを作っています。Machado (2009) のモデルで見え方をシミュレートし、Daltonize で補正。自作の診断ツールで測った個人差に合わせて、補正の強さを人ごとに最適化します。2026年10月に学会発表（福岡）。

同じ行列計算でも、実装する環境によって色空間の扱いが変わるのが面白いところです。Python / OpenCV では sRGB を自分で線形化する必要があり（ここを忘れて一度バグらせました）、Unity の Linear カラースペースでは値が既に線形なので、同じ変換を入れると二重になってしまいます。

  • Python
  • OpenCV
  • Color Vision
  • Real-time

PHOTO TAGGER

Google フォトに独自タグを付けて探すツール。

Google フォトに独自タグを付けて、数千枚の中から目的の写真を素早く探せるツール。PCはChrome拡張、スマホはPWAで役割を分け、タグデータはGoogle Driveの appDataFolder に保存するのでサーバーは不要です。Google フォトのTrusted Types CSP下で innerHTML が使えないため全UIを createElement で構築し、クロスオリジン制約のあるサムネイルはChrome側でbase64化してPWAから読めるようにしました。

SENRYU BOT

会話に紛れた「5・7・5」を見つける Discord Bot。

CHARACTER COUNTER — 文字カウント拡張

選択したテキストの文字数をその場に出す拡張。
