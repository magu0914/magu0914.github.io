STAGE 1-5 / STORY

Character Counter — 文字カウント拡張

選択したテキストの文字数を、その場に表示する Chrome / Edge 拡張機能。

Tech
Chrome 拡張 (Manifest V3) / JavaScript
Permission
storage のみ・外部通信なし
Source
GitHub
01 WHY

きっかけ

レポートや感想文には「◯◯字以上」の指定があります。確かめるたびに文字カウントのサイトを開いて、コピーして、貼り付けて……という 2〜3手間が地味に面倒 でした。

選んだら、そこに数字が出ればいい。

02 PROCESS

作るまでの 流れ

  1. Step 1選択したら文字数をバッジで出す最初はマウスを離したとき（mouseup）に数えていた。
  2. 壁サイトによって反応しない / キーボード選択で反応しないサイト側がイベントの伝わりを止めていると mouseup が届かない。
  3. Step 2選択範囲の変化そのもの（selectionchange）を見るマウスでもキーボード（Shift+矢印 / Ctrl+A）でも反応するように。
  4. Step 3iframe の中のフォームにも対応Manifest V3 の all_frames と match_origin_as_fallback を指定。
  5. Step 4貼り付けて数えるポップアップを追加全文字数・行数・原稿用紙換算（400字詰）も。
03 DESIGN

工夫したこと

  • 数え方を「提出する文字数」に合わせる。 半角・全角スペース、タブ、改行を除いて数える。
  • 絵文字も1文字。 [...text] でコードポイント単位に数えるので、絵文字が2文字にならない。
  • 入れた文章は外に出さない。 権限は storage だけ。通信は一切しない。
04 FIXES

嫌だったこと → 直したこと

嫌だったことサイトやキーボード操作によっては反応しない
→
こう直したselectionchange を主なきっかけにする
嫌だったこと選択を広げている途中に、数字が何度も書き換わる
→
こう直した120ms のデバウンスで、選び終わってから表示
嫌だったことバッジがカーソルから遠いところに出る
→
こう直した直近 1.5 秒以内のマウス位置を優先し、なければ選択範囲の右下に
嫌だったこと埋め込みフォーム（iframe）の中では使えない
→
こう直したall_frames と match_origin_as_fallback を指定

次にやること
