Photo Tagger

Google フォトに「タグ」を後付けして、数千枚の中から目的の1枚にすぐたどり着けるようにするツール。

Period
2026.05 初版 → 07 改善
Tech
Chrome 拡張 (MV3) / PWA / OAuth 2.0 / Google Drive API
Source
GitHub
01 WHY

きっかけ

Google フォトには写真が数千枚単位でたまっていきます。AI 検索は便利ですが曖昧で、アルバムで整理するのも続きません。「あの写真」に毎回たどり着けない のが不便でした。

自分で決めた言葉で、確実に見つけたい。

そこで、だれでも使い慣れている「タグ」を Google フォトに後付けすることにしました。

02 PROCESS

作るまでの 流れ

  1. 設計PC とスマホで役割を分けるタグ付けは画面の広い PC（Chrome 拡張）、探すのはスマホ（PWA）。
  2. 設計サーバーを持たないタグは各ユーザーの Google Drive の隠し領域 appDataFolder に保存。運用コストもゼロ。
  3. 壁 1Google フォト上で innerHTML が使えないTrusted Types の CSP で文字列からの DOM 生成が禁止されていたため、UI をすべて createElement で組み立てた。
  4. 壁 2スマホからサムネイルが読めないGoogle の画像 CDN が Cross-Origin-Resource-Policy: same-site で、PWA からは取得できないと特定。PC 側でタグを付けるときに 96×96 のサムネイルを base64 にして Drive に一緒に保存する方式にした。
  5. 2026.05v1.0 公開
  6. 2026.07毎日使ってみて出た不満を一気に直す2日間で 12 コミット。下の「嫌だったこと」はほとんどこの時期のもの。
03 DESIGN

工夫したこと

  • 写真の同一性。 API の制約の中で、Web 側の写真 ID（AF1Qip で始まる44文字）を主キーにし、撮影日時を補助に使う設計にした。
  • スマホは読むだけ。 スマホ側は Drive のデータを読むだけで動くので、写真本体を転送しない。
  • OAuth の審査が要らない範囲だけ使う。 機密扱いではないスコープだけで完結させ、だれでもすぐ使えるようにした。
04 FIXES

嫌だったこと → 直したこと

嫌だったことPWA を更新しても、古い画面のまま
→
こう直したService Worker をネットワーク優先に変更
嫌だったことタグを付けたはずが、保存されていないことがある
→
こう直したService Worker が止まる前に保存を完了させるよう修正
嫌だったことタグを1つずつしか入れられない
→
こう直したカンマ区切りでまとめて入力できるように
嫌だったこと付けたタグが画面に出るまで間がある
→
こう直した保存を待たずに即時反映
嫌だったこと複数タグで絞ると結果が多すぎる
→
こう直したAND 検索と除外検索を追加
嫌だったことAndroid で写真を開くとブラウザで開いてしまう
→
こう直したintent:// で純正アプリを起動し、「アプリで開く」ボタンも用意
嫌だったことページ移動のタイミングでタグ欄が別の写真のものになる
→
こう直した遅延処理の実行時に最新の URL を見直すよう修正（SPA 遷移と MutationObserver の競合）
