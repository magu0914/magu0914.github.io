STAGE 1-1 / STORY

視界 — 赤と緑が、同じに見える世界

画面全体が1型色覚のシミュレーションで描かれた世界を、色の代わりに数字で推理して進むパズルゲーム。

Play
ブラウザで遊ぶ
Tech
Unity 6 / URP / HLSL / C# / WebGL
Period
2026.09 – 10（v1 → v5 まで4回作り直し）
01 WHY

きっかけ

修士研究で、色覚特性のある人のためのリアルタイム画面補正を作っています。作者自身も1型色覚です。その補正技術を、ゲームの仕掛けとして使えないかと考えたのが始まりでした。

色覚のゲームを、色覚の体験そのもので作りたかった。

1型色覚の人にとって、赤と緑は「見えない」のではなく「見えているのに区別がつかない」ものです。そして日常では、信号の色を位置で判断するように、色以外の手がかりで色を推理して暮らしています。このゲームは、その推理を遊びにしました。

画面全体に P型シミュレーションがかかっているので、一般色覚の人も円の外では赤と緑を区別できません。全員が作者と同じ条件から始まります。

02 PROCESS

作るまでの 流れ

  1. v1 – v32つの視界を Tab で切り替えるゲーム切り替えが無料・無制限なので、とりあえず両方見るだけになり、判断が生まれず作業になった。
  2. 壁作者自身がプレイできなかった難しさの源が「赤と緑を見分けられないこと」だったため、1型色覚の作者には遊べないゲームになっていた。
  3. 2026.10.10v4: 補正を「円」にする自分のまわりの円の中だけ補正をかける。円の外は全員が同じ条件になり、作者も遊べる構造になった。
  4. 壁遊んでも「単純な作業」に感じる円がいつも隣のマスを見せてくれるので、見えている緑を踏むだけになっていた。
  5. 2026.10.14v5: 色を推理するゲームに作り替える円は立ち止まったときだけ開くようにし、進む手がかりを「踏んだ床の数字」にした。毎歩「推理して進むか、止まって確かめるか」を選ぶゲームになった。
  6. 2026.10.16v5.1 – 5.2: 既存ゲームから4つの要素を借りるマインスイーパーの 0 の連鎖、ColorADD の記号ラベル、Neon White の★評価、Wordle の今日の一問。
03 DESIGN

工夫したこと

  • 色覚フィルタをシェーダーで。 画面全体に Machado ら（2009）の1型色覚シミュレーション行列をかけ、円の内側だけ Daltonize で補正する。URP の Full Screen Pass Renderer Feature から呼んでいる。
  • カラースペースの二重変換を避ける。 研究の Python 版では sRGB を自分で線形化する必要があった（忘れて一度バグらせた）。一方 Unity の Linear カラースペースでは、シェーダーに届く時点で既に線形。同じ変換を入れると二重になるので、QualitySettings.activeColorSpace から経路を自動で選ぶようにした。
  • 色は目ではなく数値で確かめる。 作者は画面の変化を目で判定できないので、フレームバッファの画素値を測る診断を作った。補正が「効いていない気がする」の正体は、3週間一度も動いていなかったポストエフェクトだった。
  • 装飾が仕掛けを壊さないように。 床の陰影やハイライトは色味のない明るさの変化だけにした。シミュレーションは線形変換なので、赤と緑に同じ明暗をかければ、変換後も同じ色のままになる。
  • 運で死なせない。 推理だけでどこまで進めるかを Tools/deduce.py でシミュレーションし、ステージを選んでいる。今日の一問も、ゲームの中で解けることを確かめてから出す。
04 FIXES

嫌だったこと → 直したこと

嫌だったこと作者自身（1型色覚）がプレイできなかった
→
こう直した補正を自分のまわりの「円」にして、円の外は全員が同じ条件になるようにした
嫌だったこと円の外でも、一般色覚の人には赤と緑がわずかに見分けられた（作者には見えないので、画素値を測って初めて気づいた）
→
こう直したテンプレートのトーンマッピングを切り、赤と緑の差が約1階調（色差 ΔE 0.3）に戻ったことを実測した
嫌だったこと考えている間に円が開いて「確かめた」に数えられ、1歩ごとに止まるのが一番安全な遊び方になっていた
→
こう直した新しく分かった床が見えたときだけ数え、円が開き始めるまで1秒待つ。暗闇の速さはシミュレーションで調整
嫌だったことミスするとその場で盤面が組み直されて、どこで死んだのか分からない
→
こう直した死んだマスに白い「×」を1秒弱残す。赤という色に頼らず、形で伝える
嫌だったこと「本当にやり直しますか？」の確認が煩わしい
→
こう直した確認を出さない。R キー一発、ロードなしで即座に開始位置へ
嫌だったことブラウザ版では日本語が表示されなかった（OS のフォントが使えない）
→
こう直した実際に使う249字だけを抜き出したフォントを同梱（約9MB → 127KB）
05 NEXT

次にやること

作者は1型色覚なので、「円の外で赤と緑が本当に区別できないか」を自分の目では確かめられません。一般色覚の人によるプレイテストが次の課題です。あわせて、ステージ数（現在6面）と、円の大きさや縮む速さの手触りを詰めていきます。
