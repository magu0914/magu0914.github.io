STAGE 1-3 / STORY

Senryu Bot

Discord の何気ない会話に紛れ込んだ「5・7・5」を見つけて、川柳として拾い上げる Bot。

Tech
Go / discordgo / kagome (形態素解析) / SQLite
Run
Windows / Docker
Source
GitHub
01 WHY

きっかけ

チャットをしていると、たまたま5・7・5になっている発言があります。だれも気づかずに流れていくそれを、Bot が拾って「川柳です」と返してくれたら、会話が少し楽しくなるはず。

5朝起きて
7昼めし食べて
5夜眠る

ただし、変なところで切った「川柳もどき」を拾うと一気に冷めます。 この Bot はほとんど「誤検出との戦い」でした。

02 PROCESS

作るまでの 流れ

  1. Step 1形態素解析で読みを取り、5/7/5 になる区切りを探す
  2. Step 2おかしな検出を後から弾くルールを足していく誤検出が出るたびにルールを1つ足す…を繰り返した。
  3. 壁ルールを足すたびに別の誤検出が出る「悪いものを弾く」方式では終わりがない、と気づく。
  4. Step 3「正しい区切りしか許さない」方式に書き直す文節の境界をきちんと計算し、句の切れ目は文節の境界とだけ一致させる。
  5. 結果集めた誤検出 24 件をすべて解消正しい川柳の検出は維持できた。
  6. Step 4遊び方を増やす今日の一句・日次サマリー・月間MVP・詠み人当てクイズ・ランキング。
03 DESIGN

工夫したこと

  • 文節の境界を厳密に。 自立語の手前だけを区切り候補にし、名詞の連続は複合名詞としてつなげる。「バーキン」が「バー / キン」で割れない。
  • 句の切れ目は文節の境界だけ。 4つの境界を選んで 5/7/5 モーラぴったりになる組を探すので、単語の途中で切れることが構造的に起きない。
  • 文の途中から始めない。 上五の開始位置を制限し、文中に埋もれた断片の切り出しを防ぐ。
  • 言いかけで終わらせない。 「は・も・て・で・と・って」で終わる下五を弾く。「美味しいと（思います）」を拾わない。
  • 読めない漢字は補う。 辞書で読みが取れない語は補助辞書で補完。

Go の SQLite には純 Go 実装を使い、CGO なしでビルドできるようにしています。

04 FIXES

嫌だったこと → 直したこと

嫌だったこと単語の途中で切った「川柳もどき」を拾う
→
こう直した複合名詞や接頭・接尾辞をつなげて文節を計算
嫌だったこと文の真ん中だけを切り出して川柳にしてしまう
→
こう直した上五の開始位置を制限
嫌だったこと「〜と」「〜て」で終わる言いかけを拾う
→
こう直した下五末尾の助詞を制限
嫌だったこと誤検出を直すたびに別の誤検出が出る（イタチごっこ）
→
こう直したブラックリスト方式をやめ、正しい境界だけを許すホワイトリスト方式に書き直し
嫌だったこと検出が多すぎてうるさいと感じる人もいる
→
こう直した/detect off で自分だけ、/mute でチャンネルごと止められるように
